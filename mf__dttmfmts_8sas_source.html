2 @file
3 @brief Returns the SAS format names that carry a date, datetime or time value
4
5 @details Prints a quoted, comma separated list of format NAMES, for use in
6 open code or in generated code:
7
8 if upcase(fmt) in (%mf_dttmfmts(DATE)) then fmttype='DATE';
9 else if upcase(fmt) in (%mf_dttmfmts(DATETIME)) then fmttype='DATETIME';
